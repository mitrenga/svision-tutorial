# helloworld/vga

The smallest possible svision application on the VGA platform (`VGAPlatform`):
one model, one `TextEntity` in the machine's font (`VGAFonts8x16`) — light grey text on the black screen of the DOS prompt (colours 7 and 0 of the default palette).
No build: `config/config.php` has `$devMode = true`. One of the Hello worlds of the
`svision-tutorial` project, one per platform.
