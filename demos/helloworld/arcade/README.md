# helloworld/arcade

The smallest possible svision application on the Arcade platform (`ArcadePlatform`):
one model, one text entity (font `Fonts5x5`) — white text on the black portrait 224 x 256 screen of the cabinet in the library's 5x5 font.
No build: `config/config.php` has `$devMode = true`. One of the Hello worlds of the
`svision-tutorial` project, one per platform.
