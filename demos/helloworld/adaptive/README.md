# helloworld/adaptive

The smallest possible svision application on the Adaptive platform (`AdaptivePlatform`):
one model, one text entity (font `VGAFonts8x16`, the IBM PC's) — white text on the light blue desktop that follows the window (512 units across; an entity of width 1 is as wide as its parent).
No build: `config/config.php` has `$devMode = true`. One of the Hello worlds of the
`svision-tutorial` project, one per platform.
