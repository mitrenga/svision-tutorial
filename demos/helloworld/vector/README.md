# helloworld/vector

The smallest possible svision application on the Vector platform (`VectorPlatform`):
one model, one text entity (font `AtariVectorFont`) — the beam on the black 1024 x 768 XY monitor: `VectorTextEntity` in the font of the Atari vector ROMs, capitals 32 high, full intensity.
No build: `config/config.php` has `$devMode = true`. One of the Hello worlds of the
`svision-tutorial` project, one per platform.
