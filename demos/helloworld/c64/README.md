# helloworld/c64

The smallest possible svision application on the Commodore 64 platform (`C64Platform`):
one model, one `TextEntity` in the machine's font (`C64Fonts8x8`) — light blue text on the blue screen with the light blue border of the machine switched on.
No build: `config/config.php` has `$devMode = true`. One of the Hello worlds of the
`svision-tutorial` project, one per platform.
