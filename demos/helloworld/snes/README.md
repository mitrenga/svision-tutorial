# helloworld/snes

The smallest possible svision application on the Super Nintendo platform (`SNESPlatform`):
one model, one text entity (font `Fonts5x5`) — white text on the black 256 x 224 screen in the library's 5x5 font (the console has no font ROM).
No build: `config/config.php` has `$devMode = true`. One of the Hello worlds of the
`svision-tutorial` project, one per platform.
