# helloworld/webgl2

The smallest possible svision application on the 3D (WebGL2) platform (`WebGL2Platform`):
one model, the text HELLO WORLD! built of boxes (`Mesh.box` for every rectangle of the
library's 5x5 font) in a `SceneEntity`, the plane of the text tilted 45 degrees back and the whole text turned 45 degrees
about the vertical axis, so the line runs away from the camera and shrinks in its perspective.
No build: `config/config.php` has `$devMode = true`. One of the Hello worlds of the
`svision-tutorial` project, one per platform.
