# helloworld/zx

The smallest possible svision application on the ZX Spectrum platform (`ZXPlatform`):
one model, one `TextEntity` in the machine's font (`ZXFonts8x8`) — red text on white paper with a green border.
No build: `config/config.php` has `$devMode = true`. One of the Hello worlds of the
`svision-tutorial` project, one per platform.
