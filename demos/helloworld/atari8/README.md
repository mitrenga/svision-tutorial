# helloworld/atari8

The smallest possible svision application on the Atari 8-bit platform (`Atari8Platform`):
one model, one `TextEntity` in the machine's font (`Atari8Fonts8x8`) — text on the blue Graphics 0 field of the OS with a lighter blue border (COLPF2 $94, COLBK $98 — black at power-on, the characters in the luminance of COLPF1).
No build: `config/config.php` has `$devMode = true`. One of the Hello worlds of the
`svision-tutorial` project, one per platform.
